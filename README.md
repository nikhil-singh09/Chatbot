# Document-Based Chatbot

A simple conversational chatbot that responds to user queries based on document content and recognizes basic greetings.

## Features

- Greets the user when the program starts.
- Accepts text queries through an interactive prompt.
- Provides responses based on the document content.
- Handles basic greetings.
- Supports `bye` and `goodbye` as exit commands.

## Usage

1. Open the project folder and review the source code.
2. Install the dependencies required by the implementation.
3. Run the main Python script from the project directory.
4. Enter a query when prompted.
5. Type `bye` or `goodbye` to exit.

> The exact script name, document format, and dependency list should be confirmed from the source files before adding copy-paste installation commands.

## Example interaction

```text
Chatbot: Hello! How can I help?
You: Ask a question about the document
Chatbot: Responds based on the available document content
You: bye
```
